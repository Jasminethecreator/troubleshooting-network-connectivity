# Troubleshoot Network Connectivity

## Objective
Diagnose network issues by testing internet connectivity and identifying potential connectivity problems.

## Scenario
This lab simulated a basic network troubleshooting scenario on a virtual machine, testing whether the system could reach an external server.

## Tasks Completed
Used the ping command to test network connectivity, targeting a Microsoft server to verify internet access.
